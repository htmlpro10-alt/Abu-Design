# Abu Design Studio & Print Lab (Madurai)

Official website for Abu Design (South Gate, Periyar, Madurai) showcasing all 24 core manufacturing lines:
- **LED Signage & 3D Letters**: LED Sign Board, Acrylic Letter, Trim Cap Letter, Titanium Letter, LED Lighting Box, Flex Boards.
- **Flex & UV Printing**: Flex, Star Flex, Vinyl Sticker, Inzet Print, UV Print, Photo Frame.
- **Print & Commercial Stationery**: Business Card, Brochure, Invitations, Wedding Card, Letter Head, Certificate, Bill Book, Office Cover, ID Cards, Label & Sticker, Calendar, Stamp, Sunpack Sheet, Wall Poster.

## 🚀 1-Click Deploy to Vercel

### Option 1: Deploy via GitHub (Recommended)
1. Push this folder to a new GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Vercel will automatically detect **Vite** with these settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **"Deploy"**. Your site will be live on your custom `.vercel.app` domain within 60 seconds!

---

### Option 2: Deploy via Vercel CLI
If you have Node.js installed on your computer:
```bash
# 1. Install Vercel CLI globally
npm install -g vercel

# 2. In this folder, run:
vercel

# 3. For production deployment:
vercel --prod
```
